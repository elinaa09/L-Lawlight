# L-Lawliet

<img class="hidden-text" src="assets/lpfp.png" alt="img" />


A website about L Lawliet from deathnote,the world's greatest detective from Death Note. Built with plain HTML, CSS and JavaScript.

#Features
-Case file with L's name, aliases, birthday, height and where he grew up
-Clickable fact boxes: click a box to open it and see the text and image, click again to close it
-Gallery page with more pictures of L
-Dark theme with a full-screen background image

#What i learnt
-Inserting images in web
-openable boxes through js
